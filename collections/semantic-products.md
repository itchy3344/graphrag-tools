# Semantic models and enterprise applications

These products span semantic derivation, governed models, and graph-grounded applications. Classify each output separately: a semantic model defines meaning, a populated knowledge graph represents specific entities and assertions, and an answering application selects evidence and composes a response. A product may cover several outputs through different components; the profiles make those boundaries explicit.

## Tool profiles

### [Flow.BI](../tools/flow-bi.md)

Semantic-model discovery from enterprise sources, with separate loaders for graph population and document enrichment.

### [Graphwise GraphRAG](../tools/graphwise-graphrag.md)

Graph-grounded conversational workflows combining semantic modeling, graph queries, and vector retrieval.

### [metaphactory](../tools/metaphactory.md)

Semantic knowledge modeling and enterprise applications using graph queries and unstructured RAG.

### [Stardog Voicebox](../tools/stardog-voicebox.md)

Conversational enterprise-graph access combining query, document retrieval, analysis, and source attribution paths.

### [TopBraid EDG](../tools/topbraid-edg.md)

Semantic governance and modeling with documented content and query capabilities supporting GraphRAG applications.

## Compare complete responsibilities

Use the linked profiles to distinguish definitions, populated facts, evidence retrieval, and answering. Then test identity, relationship provenance, freshness, citation support, and the actual graph/schema integration.
