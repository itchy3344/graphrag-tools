# Persistent and temporal context

Graph memory products emphasize knowledge that changes as events and interactions arrive. Evaluate the meaning of current, historical, superseded, and uncertain facts. A graph of agent workflow steps is different from domain knowledge available for retrieval, and persistence alone does not establish correct temporal answers or source attribution.

## Tool profiles

### [cognee](../tools/cognee.md)

Persistent AI memory and knowledge processing supplying context for graph-assisted applications.

### [Graphiti](../tools/graphiti.md)

Temporal knowledge graphs for changing facts, source provenance, and AI-agent context.

## Compare complete responsibilities

Use the linked profiles to distinguish definitions, populated facts, evidence retrieval, and answering. Then test identity, relationship provenance, freshness, citation support, and the actual graph/schema integration.
