# Graph engines and managed services

Graph engines provide storage or query access, while a managed GraphRAG service may additionally control ingestion and retrieval. These are different operating boundaries. Verify database API, graph schema, partitioning, indexes, release, and service configuration. A framework naming a database does not establish that it can consume every graph in that database.

## Tool profiles

### [Amazon Bedrock Knowledge Bases GraphRAG](../tools/amazon-bedrock-knowledge-bases-graphrag.md)

A managed document-driven GraphRAG service using Neptune Analytics for graph-enhanced retrieval.

### [Amazon Neptune Database](../tools/amazon-neptune-database.md)

Managed graph services used by custom and managed graph-enhanced AI applications.

### [ArangoDB](../tools/arangodb.md)

A multi-model database and platform combining graph, document, vector, and search capabilities.

### [Azure Cosmos DB for Apache Gremlin](../tools/azure-cosmos-db-for-apache-gremlin.md)

Managed graph storage and Gremlin traversal with API-specific compatibility considerations.

### [FalkorDB](../tools/falkordb.md)

A graph runtime underlying the FalkorDB GraphRAG SDK and packaged Server ecosystem.

### [Google Spanner Graph](../tools/google-spanner-graph.md)

Graph querying over a relational foundation with documented graph/vector AI integration paths.

### [Memgraph](../tools/memgraph.md)

A graph database and integration ecosystem supporting graph-backed retrieval applications.

### [Neo4j / Aura](../tools/neo4j-aura.md)

Property graph storage and Cypher query infrastructure supporting a separate GraphRAG application layer.

### [PuppyGraph](../tools/puppygraph.md)

Graph query access over relational data as an alternative to materializing every record in a separate graph store.

### [TigerGraph GraphRAG](../tools/tigergraph-graphrag.md)

Enterprise graph/vector retrieval and AI integration capabilities around connected operational data.

## Compare complete responsibilities

Use the linked profiles to distinguish definitions, populated facts, evidence retrieval, and answering. Then test identity, relationship provenance, freshness, citation support, and the actual graph/schema integration.
