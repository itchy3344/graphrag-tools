# Evaluation and observability

These tools help test and inspect an AI application. Add task-specific tests for entity selection, relationship paths, source versions, permissions, and citation support. General answer metrics should be paired with known evidence. Trace the graph queries and retrieval decisions as well as model calls so a fluent but incorrect response can be diagnosed.

## Tool profiles

### [DeepEval](../tools/deepeval.md)

AI evaluation and test pipelines supporting evidence-aware GraphRAG quality checks.

### [Langfuse](../tools/langfuse.md)

AI tracing, prompt management, and evaluation supporting observability of a GraphRAG application.

### [Phoenix](../tools/phoenix.md)

Tracing and evaluation capabilities supporting reproducible diagnosis of graph-backed AI applications.

### [Ragas](../tools/ragas.md)

Retrieval and answer evaluation metrics supporting measurement of a GraphRAG workflow.

## Compare complete responsibilities

Use the linked profiles to distinguish definitions, populated facts, evidence retrieval, and answering. Then test identity, relationship provenance, freshness, citation support, and the actual graph/schema integration.
