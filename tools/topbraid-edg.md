# TopBraid EDG

TopBraid EDG contributes semantic governance and modeling within a broader platform. Its documented GraphRAG foundations include content processing, vector search combined with SPARQL, and Python integration. Those features provide application building blocks; the selected edition and release determine the configuration under evaluation.

## Documented capabilities and boundaries

Semantic governance and GraphRAG foundations; documented features include content processing, vector search with SPARQL, and Python integration. [Primary evidence](https://ww2.topquadrant.com/release-note/9-0/).

Separate the governed semantic assets from populated facts and from a complete answering interface. A model may be maintained in the platform while another component performs retrieval, context assembly, and generation.

## Place in an implementation

An illustrative assessment could define a small governed domain, connect a document corpus, and inspect a query combining graph context with retrieved content. Change a definition and a document separately to see how each affects evidence selection.

## Dependencies and scope

Check release, ingestion, and answering components. Record separately which component defines meaning, populates facts, selects evidence, and generates answers. Shared branding or database support does not establish a working integration.

## What to verify in an evaluation

- Which EDG components handle semantic definitions, document ingestion, evidence retrieval, and answer generation in the selected release?
- Distinguish the semantic definitions, populated entity facts, retrieval result, and generated response in a demonstration.
- Trace a claim back to the source and show how a change in meaning, identity, or source data reaches the answer.
